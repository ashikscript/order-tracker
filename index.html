⚙️ একবার Firebase Setup করো
এরপর সব device এ same data দেখাবে এবং data চিরকাল Google এর server এ থাকবে।
1
console.firebase.google.com এ Google account দিয়ে login করো → Add project → যেকোনো নাম দাও → Continue → Create project
2
Project এর ভেতরে বামে Build → Realtime Database → Create database → যেকোনো location → Start in test mode → Enable click করো
3
Database তৈরি হলে এরকম একটা URL দেখবে:
https://your-project-default-rtdb.firebaseio.com
সেটা copy করে নিচে paste করো।
