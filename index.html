One-time Firebase Setup
After this, all your devices will show the same data — stored permanently on Google's servers.
1
Go to console.firebase.google.com → Sign in with Google → Add project → Enter any name → Create project
2
Inside the project → Build → Realtime Database → Create database → Any location → Start in test mode → Enable
3
Copy the database URL shown at the top:
https://your-project-default-rtdb.firebaseio.com
Paste it below.
