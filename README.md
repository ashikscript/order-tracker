# 📦 Order Tracker

A simple and beginner-friendly order tracking system built for learning and small projects.

## 🚀 Features

* Track order status easily
* Simple and clean UI
* Beginner-friendly codebase
* Easy to customize
* Fast setup

## ⚡ Getting Started

Clone the repository:

```bash
git clone https://github.com/ashikscript/order-tracker.git
```

Go to the project folder:

```bash
cd order-tracker
```

Open `index.html` in your browser.
