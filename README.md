# 📦 Order Tracker

A simple and beginner-friendly order tracking project.

## 🚀 Features

* Track order status
* Clean UI
* Easy to customize

## ⚡ Setup

```bash
git clone https://github.com/ashikscript/order-tracker.git
cd order-tracker
```

Open `index.html` in your browser.
